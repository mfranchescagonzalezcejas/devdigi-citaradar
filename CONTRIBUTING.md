# Contributing

Develop on a feature branch from `develop` and open a PR. Protected `develop` and `main`; merge commits only. Keep work units under 1000 changed lines where possible. Include acceptance tests and offline E2E evidence. CI never accesses the live SEPE portal. Do not upload screenshots or logs with user names, DNI/NIE, browser cookies or session tokens. Disclose any proposal for automatic polling, authentication change or new provider separately for terms review.
